========================================
COMPLETE PAGE & COMPONENT INVENTORY
========================================

Excluding: Admin pages, Landing page (already done)


SECTION A — AUTH (2 pages)
--------------------------
A1. Login (phone number input, send OTP)
A2. Verify OTP (6-digit input, resend timer, redirect logic)


SECTION B — CUSTOMER PAGES (13 pages)
--------------------------------------
B1.  Home (logged-in dashboard: wallet balance, category grid, recent orders)
B2.  Search (search input, vehicle bar, category chips, part grid, load more)
B3.  Cart (vehicle selector, line items, qty controls, order summary, delivery weight)
B4.  Checkout (address input, delivery notes, items accordion, pricing breakdown, payment method select)
B5.  Orders list (tab nav: Active/Completed/All, paginated order cards, empty state)
B6.  Order detail (status badge, timeline, items, payment, delivery, rating form, cancel flow)
B7.  Receipt (printable receipt layout: header, items table, pricing, payment info)
B8.  Wallet (balance card, held balance, top-up button, transaction history with filters)
B9.  Account (profile header, contact info, nav links, edit mode, setup form for new users)
B10. Vehicles (vehicle list, add/edit/remove, empty state)
B11. Loyalty (tier progress, all tiers list with requirements and benefits)
B12. How Delivery Works (info page: weight tiers table, free delivery, examples)
B13. How Loyalty Works (info page: tiers breakdown, what counts, timing)


SECTION C — RUNNER PAGES (6 pages)
-----------------------------------
C1. Runner Dashboard (shift status card, float balance, start/end shift, assigned orders list)
C2. Runner Order Detail (order info card, SLA timer, accept/reject, items with found/unavailable states, clarification thread, complete handoff)
C3. Current Shift (active shift stats: duration, orders, sourced total, commission, float balance)
C4. Shift History (list of past shifts)
C5. Shift Detail (individual past shift summary and reconciliation data)
C6. Runner Account (staff profile view, role label, logout)


SECTION D — RIDER PAGES (4 pages)
----------------------------------
D1. Rider Dashboard (active deliveries list, empty state)
D2. Rider Delivery Detail (status bar, COD banner, pickup/delivery actions, customer info, delivery attempts, high-value warning)
D3. Rider History (stats grid, deliveries grouped by date, load more)
D4. Rider Account (staff profile view, role label, logout)


SECTION E — MARKETING PAGES (4 pages)
--------------------------------------
E1. Features listing
E2. Feature detail (dynamic: /features/[slug])
E3. Blog listing
E4. Blog post detail (dynamic: /blog/[slug])


SECTION F — MODALS (5 components)
----------------------------------
F1. Cancel Order confirmation (from B6 Order Detail)
F2. Refund confirmation (from B6 Order Detail, for price changes)
F3. End Shift summary (from C1 Runner Dashboard and C3 Current Shift)
F4. Delete Vehicle confirmation (from B10 Vehicles)
F5. Delete/Decline Delivery confirmation (from D2 Rider Delivery Detail)


SECTION G — BOTTOM SHEETS (8 components)
-----------------------------------------
G1. Top Up Wallet form (from B8 Wallet — amount input, Paystack trigger)
G2. Add Vehicle form (from B10 Vehicles — make, model, year, spec, nickname)
G3. Edit Vehicle form (from B10 Vehicles — pre-filled vehicle form)
G4. Part Detail Sheet (from B2 Search — part info, add to cart, qty selection)
G5. Mark Item Found (from C2 Runner Order Detail — vendor select, price entry, QC photo upload)
G6. Mark Item Unavailable (from C2 Runner Order Detail — reason dropdown)
G7. Pickup Confirmation (from D2 Rider Delivery Detail — optional photo for high-value)
G8. Delivery Confirmation (from D2 Rider Delivery Detail — photo, COD collection)
G9. Delivery Failure Report (from D2 Rider Delivery Detail — reason, notes, photo, location)


TOTAL: 29 pages + 14 overlay components = 43 design deliverables
